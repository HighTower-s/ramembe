# Remembe

เว็บรวมข้อสอบเก่าไว้ให้รุ่นน้องได้ดูและลองฝึกทำ (หน้าแรกตั้งใจไม่บอกว่าเว็บนี้เกี่ยวกับอะไร)

> โจทย์ทั้งหมดเรียบเรียงขึ้นใหม่จากความจำของรุ่นพี่ ไม่ใช่ต้นฉบับทุกคำ
> ส่วนที่มี **(เดาเติม)** คือรายละเอียดที่จำไม่ได้แน่ชัด ใส่ไว้ให้โจทย์ครบเพื่อฝึกทำ

## วิธีเปิด

เปิด `index.html` ด้วย Live Server แล้วพิมพ์ชื่อกด Enter เพื่อเข้าหน้ารวมข้อสอบ

**ข้อ 1 ต้องเปิด json-server ก่อน** ไม่งั้นตารางจะโหลดข้อมูลไม่ขึ้น

```bash
npx json-server exam1/db.json --port 3000
```

## โครงสร้าง

| ไฟล์ / โฟลเดอร์ | คืออะไร |
|---|---|
| `index.html` | หน้าแรก พิมพ์ชื่อแล้วกด Enter |
| `exams.html` | หน้ารวมข้อสอบ ทั้ง theory และ coding |
| `problem.html?id=N` | หน้าอ่านโจทย์ แปลงจาก `examN/README.md` มาแสดงเป็นเว็บ พร้อมแปะไฟล์ JSON ของข้อนั้นไว้ท้ายหน้า |
| `site.css` | สไตล์ของตัวเว็บรวม (ไม่เกี่ยวกับโค้ดเฉลย) |
| `gate.js` / `hub.js` / `problem.js` / `md.js` | สคริปต์ของตัวเว็บรวม |
| `exam1/` `exam2/` `exam3/` | โจทย์แต่ละข้อ ข้างในมี `README.md` และ `solution/` |

## ข้อสอบ

**ส่วนที่ 1 · Theory** — 5 ข้อ อยู่ในหน้า `exams.html` ให้โจทย์อย่างเดียว ไม่มีเฉลย

**ส่วนที่ 2 · Coding** — 3 ข้อ มีเฉลยให้เทียบในโฟลเดอร์ `solution/` ของแต่ละข้อ

| ข้อ | เรื่อง | ต้องรู้ |
|---|---|---|
| 1 | ตารางพนักงาน + กราฟความสำเร็จ + หน้าแก้ไข | `fetch`, `GET`/`PUT`, json-server |
| 2 | เลือกสาขาจาก dropdown แล้วแสดงรายการสินค้า | DOM ล้วน ห้าม `innerHTML` |
| 3 | Grid รูปภาพที่เปลี่ยนคอลัมน์ตามขนาดจอ | CSS Grid, Media Query |

ทั้งหมดเป็น HTML/CSS/JavaScript ล้วน ไม่มี framework ไม่ต้อง build

ข้อสอบชุดนี้ใช้ไฟล์ JSON เป็นแหล่งข้อมูลอย่างเดียว ยังไม่มีการต่อ Database เพราะอาจารย์ยังไม่สอน
