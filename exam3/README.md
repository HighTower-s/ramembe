# ข้อ 3 · Responsive Grid แสดงรูปภาพตามขนาดหน้าจอ

> โจทย์นี้เขียนขึ้นใหม่จากความจำของรุ่นพี่ ไม่ใช่โจทย์ต้นฉบับทุกคำ
> ส่วนที่มี **(เดาเติม)** คือรายละเอียดที่จำไม่ได้แน่ชัด ใส่ไว้ให้โจทย์ครบเพื่อฝึกทำ

## ข้อมูลที่ให้มา

ไม่มีไฟล์ข้อมูล ให้สร้างการ์ดเองในโค้ด ทั้งหมด **10 ใบ** หมายเลข 0 ถึง 9

การ์ดแต่ละใบประกอบด้วย

| ส่วน | รายละเอียด |
|---|---|
| หัวการ์ด | ข้อความ `หมายเลข N` เมื่อ N คือ 0–9 จัดกึ่งกลาง ตัวหนา |
| รูป | กล่องสี่เหลี่ยมจัตุรัสสีฟ้า มุมมน ข้างในมีตัวเลข `N` สีขาวขนาดใหญ่จัดกึ่งกลาง |

**(เดาเติม)** ตัวอย่างใช้กล่องสีฟ้ากับตัวเลขแทนไฟล์รูปจริง ถ้ามีไฟล์รูปก็เปลี่ยนเป็น `<img>` ได้ ตรรกะ grid เหมือนกัน

## สิ่งที่ต้องทำ

1. สร้างการ์ดทั้ง 10 ใบ **ด้วยวิธี DOM** คือ `document.createElement`, `textContent`, `appendChild` ห้ามใช้ `innerHTML` ประกอบ string เป็นแท็ก
2. ใช้ลูปสร้างการ์ด ห้ามพิมพ์ HTML ของการ์ดซ้ำ 10 ชุดเอง
3. จัดการ์ดเป็น **grid** ที่จำนวนคอลัมน์เปลี่ยนตามความกว้างหน้าจอ

| ความกว้างหน้าจอ | จำนวนคอลัมน์ |
|---|---|
| มากกว่า 800px | 4 คอลัมน์ |
| ไม่เกิน 800px | 2 คอลัมน์ |
| ไม่เกิน 600px | 1 คอลัมน์ |

4. ต้องทำด้วย **CSS Media Query** ไม่ใช่การเช็ก `window.innerWidth` ใน JavaScript
5. ย่อ-ขยายหน้าต่างเบราว์เซอร์แล้วเลย์เอาต์ต้องเปลี่ยนทันทีโดยไม่ต้องรีเฟรช
6. **(เดาเติม)** รูปต้องไม่ล้นการ์ดและไม่เสียสัดส่วนในทุกขนาดจอ

## เกณฑ์ให้คะแนน (เดาเติม, รวม 10 คะแนน)

| รายการ | คะแนน |
|---|---|
| สร้างการ์ดครบ 10 ใบ หัวข้อ `หมายเลข 0` ถึง `หมายเลข 9` | 2 |
| ใช้ DOM สร้าง element จริง ไม่ใช้ `innerHTML` | 2 |
| ใช้ลูปสร้างการ์ด ไม่ hardcode ซ้ำ | 1 |
| จอมากกว่า 800px ได้ 4 คอลัมน์ | 2 |
| จอไม่เกิน 800px ได้ 2 คอลัมน์ | 1 |
| จอไม่เกิน 600px ได้ 1 คอลัมน์ | 1 |
| ย่อ-ขยายแล้วเปลี่ยนทันที รูปไม่ล้น ไม่เสียสัดส่วน | 1 |

## คำใบ้

- ต้องมี `<meta name="viewport" content="width=device-width, initial-scale=1.0">` ไม่งั้น media query จะไม่ทำงานบนมือถือ
- grid 4 คอลัมน์: `display: grid; grid-template-columns: repeat(4, 1fr); gap: 16px;`
- media query เขียนทับของเดิมได้ ลำดับสำคัญ ต้องเรียง `max-width: 800px` ก่อน `max-width: 600px` เพราะอันหลังต้องชนะ
- ทำกล่องให้เป็นจัตุรัสเป๊ะ ๆ ด้วย `aspect-ratio: 1`
- จัดตัวเลขกึ่งกลางกล่อง: `display: flex; align-items: center; justify-content: center;`
- ขนาดตัวเลขให้ยืดตามการ์ด: `font-size: clamp(3rem, 12vw, 6rem)`
- ทดสอบด้วย DevTools โหมด responsive ลากความกว้างดูที่ 1000px, 700px, 500px
