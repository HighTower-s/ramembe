ส่วนที่ 1

Theory

5 ข้อ ไม่มีเฉลย

  1. 1
    ให้อธิบายหลักการของวิธีการในการส่งข้อมูลจาก Form ไปยัง Server แบบ GET และ POST ว่าเป็นอย่างไร รวมถึงให้อธิบายส่วนประกอบของชุดข้อมูลนั้น
  2. 2
    วาดรูป และอธิบาย Client-Server model
  3. 3
    JavaScript มีบทบาทหรือทำหน้าที่สำคัญอย่างไรต่อการพัฒนาเว็บไซต์ในฝั่ง client-side ให้อธิบาย
  4. 4
    DOM จะนำเสนอเอกสารในรูปแบบลำดับชั้นแบบ Tree ของ Object node ซึ่งประเภทของ node ใน Tree นั้นมีทั้งหมดกี่ประเภท ให้บอกถึงคุณลักษณะของ Node เหล่านั้น
  5. 5
    Fundamental Techniques บอกและอธิบาย หรือ Three layers of Web design รุ่นพี่จำไม่แน่ใจว่าข้อนี้ถามอันไหน อ่านเตรียมไว้ทั้งสองอย่าง
ส่วนที่ 2

Coding

3 ข้อ แต่ละข้อมีโจทย์เต็มและเฉลยให้เทียบ

ข้อ 1 · fetch + PUT

ตารางพนักงาน + กราฟความสำเร็จ

ดึงข้อมูลพนักงานจาก json-server มาแสดงเป็นตาราง พร้อมแถบกราฟตามค่า Progress และหน้าฟอร์มแก้ไขที่บันทึกกลับด้วย PUT

ดูเฉลย อ่านโจทย์
ข้อ 2 · DOM

เลือกสาขาแล้วแสดงรายการสินค้า

โหลด JSON ซ้อนสองชั้น สร้าง dropdown จากรหัสสาขา แล้ววาดตารางสินค้าพร้อมยอดรวมด้วยวิธี DOM ล้วน ห้ามใช้ innerHTML

ดูเฉลย อ่านโจทย์
ข้อ 3 · Responsive

Grid รูปภาพตามขนาดหน้าจอ

สร้างการ์ด 10 ใบด้วย DOM แล้วจัดเป็น grid ที่เปลี่ยนจำนวนคอลัมน์ตามความกว้างจอ 4 / 2 / 1 ด้วย media query

ดูเฉลย อ่านโจทย์
